# School Dynamics web app

React + TypeScript + Vite app with staff and parent portals. Entry layout: `src/pages/LandingPage.tsx`.

## Run

```bash
cd webapp
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Layout

- `src/pages/` — routes (staff, parent, landing)
- `src/context/` — auth and school data
- `src/data/mockData.ts` — school name, seeds, helpers

The static marketing site in the repo root (`../index.html`) is separate from this app.
